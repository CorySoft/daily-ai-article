# 让AI一步步带你从选题到成片：一个「确认门控」式视频生成工作流

> 好的AI工具不是替你做完一切，而是在关键节点让你做关键决策。

在AI视频制作领域，大多数工具都在追求「一键生成」的极致体验。但现实是，AI一次性输出往往伴随着大量返工——风格不对、人物不一致、文案跑偏，最终用户不得不从头来过。

GitHub上一个名为 **image-story-video-wizard** 的项目，选择了一条反直觉的路径：**把控制权还给用户，在每一步关键节点设置「确认门」**。它不是最快的工具，但可能是目前最符合人类创作逻辑的AI视频工作流。

## 从「一键生成」到「步步确认」的设计哲学

`image-story-video-wizard` 是一个专为 Codex 和 WorkBuddy 设计的 Skill，它的核心定位是**分步式AI视频生成工作流**，专为AI讲书、历史故事、情感故事类内容设计。

但真正让它脱颖而出的，不是功能清单，而是**设计哲学**。

传统AI视频工具的痛点在于：用户输入一个模糊需求，AI输出一个完整结果，然后发现方向完全错误，不得不从头再来。这种「黑盒式」生成对复杂创作任务来说是灾难性的。

这个项目的解决方案很朴素：**16个阶段，每个关键节点强制确认**。

> 对标方向没确认，不做写作包；文案没定稿，不生成完整配音；画风没确认，不批量生图；预览没通过，不渲染最终成片。

这种「确认门控」机制看似低效，实则精准地匹配了人类创作的心理节奏——**每步只让你做关键决策，把执行交给AI**。

## 16阶段工作流：一个精心设计的创作旅程

完整流程从 `START` 到 `FEEDBACK`，共16个阶段：

`START → BRIEF → BENCHMARKS → WRITING_PACK → SCRIPT → VOICE → STORYBOARD → VISUAL_STYLE → CHARACTER_ANCHORS → IMAGE_PROMPTS → IMAGE_GENERATION → ASSET_QC → MUSIC → PREVIEW → FINAL_RENDER → FEEDBACK`

每个阶段都有明确的目标和交付物。更重要的是，**每轮对话都会清晰告知用户五件事**：

- 现在进行到哪一步
- AI现在会做什么
- 用户现在只需要做什么
- 完成后会交付什么
- 确认后下一步是什么

这种「五段式引导」极大降低了用户的认知负担。你不需要知道整个流程的复杂细节，只需要专注于当前这一步。

## 状态持久化：换宿主也能无缝续接

这是该项目最被低估的技术亮点。

项目通过 `PROJECT_STATE.json` 文件持久化保存当前阶段、已确认决定、产物路径和下一个需要用户回答的问题。**这意味着你可以从Codex切换到WorkBuddy，或者中途退出后继续，状态完全保留。**

在AI工具生态日益碎片化的今天，这种「跨宿主恢复」能力显得尤为珍贵。你的创作资产不再绑定于某个特定工具或会话，而是真正属于你自己。

更巧妙的是**失败回滚机制**：某一步失败时，只回到最早受影响的阶段，不会把整个项目推倒重来。这种「局部修复」而非「全局重置」的设计，大幅降低了创作过程中的挫折感。

## 技术架构：Python状态机的优雅实践

从技术角度看，这个Skill基于Python状态机构建，单元测试覆盖16个阶段和五段式引导逻辑。

```bash
python3 -m unittest discover -s tests -v
```

状态机设计确保了流程的确定性和可预测性——这是工程思维对创作流程的赋能。每个阶段的状态转换都有明确的前置条件和后置验证，避免了AI「自由发挥」导致的流程失控。

项目还集成了多个外部能力：豆包Seed-TTS 2.0用于配音，Kimi长上下文模型用于文案创作，HyperFrames用于视频组装。这种「按需调用」的设计既保证了质量，又避免了过度依赖单一模型。

## 快速上手：一行命令启动创作

安装非常简单。在Codex中发送：

> 请使用 skill-installer 从 https://github.com/aaronyi97/image-story-video-wizard 安装 Skill。

安装完成后，直接说：

> 使用 image-story-video-wizard 开始一个新项目。我想做一期【选题】的图片联播视频，请主动带我往下做。

项目会主动推进，每次只让你提供当前必需的材料或做当前确认。你不需要记住整个流程，只需要跟随引导。

对于终端用户，也可以通过git clone安装：

```bash
git clone https://github.com/aaronyi97/image-story-wizard.git ~/.codex/skills/image-story-video-wizard
```

## 适用场景与展望

这个Skill特别适合以下几类项目：

- **AI讲书、历史故事、情感故事**：需要人物一致性、固定画风、字幕和文字卡的静态图叙事视频
- **播客音频配图联播视频**：已有音频素材，需要配图生成视频
- **需要多轮迭代优化的内容**：确认门控机制允许你在每个阶段反复打磨

但对于只需要一篇文案、一张图或普通剪辑的用户，这个Skill可能过于「重」了。它的设计哲学是**深度创作**而非**快速产出**。

随着AI视频工具生态的成熟，「确认门控」式工作流或许会成为复杂创作任务的标准范式。当AI越来越擅长执行，人类的价值将更多体现在**决策和审美判断**上。这个项目的意义，正是重新定义了人机协作的边界。
