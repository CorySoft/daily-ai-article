## 项目简介：极简主义者的本地 AI 方案

Ollama 是一个开源的本地大模型运行框架，由 AMD 前工程师 Justin Shell 等人开发。它的核心理念极其简单：**让运行开源模型像安装一个应用一样简单**。

项目采用 Go 语言开发，基于 llama.cpp 后端，支持 GGUF 格式的模型文件。截至目前，GitHub 已获得 **179,656 颗 Star**，成为本地 AI 领域最受欢迎的开源项目之一。

与传统方案（如直接调用 llama.cpp、vLLM 等）相比，Ollama 的差异化优势在于：

- **零配置起步**：一条命令安装，开箱即用
- **统一模型库**：内置 `ollama.com/library`，涵盖数十种主流模型
- **多平台覆盖**：macOS、Windows、Linux、Docker 全支持
- **开发者友好**：提供 REST API 和 Python/JS 官方 SDK

## 核心特性：为什么选择 Ollama？

**1. 模型生态丰富**

Ollama 内置模型库支持 DeepSeek、Gemma、Qwen、Llama、Mistral 等主流开源模型。无论你是需要轻量级推理还是高性能对话，都能在库中找到合适的选择。

**2. 开发集成便捷**

提供完整的 REST API 和官方 SDK：

```python
from ollama import chat

response = chat(model='gemma4', messages=[
  {'role': 'user', 'content': 'Why is the sky blue?'}
])
print(response.message.content)
```

```javascript
import ollama from "ollama";

const response = await ollama.chat({
  model: "gemma4",
  messages: [{ role: "user", content: "Why is the sky blue?" }]
});
console.log(response.message.content);
```

**3. 一键集成主流工具**

Ollama 支持与 Claude Code、Codex、Copilot CLI 等开发工具直接集成，一条命令即可启动：

```bash
ollama launch claude
```

**4. 跨平台与容器化**

无论是个人开发机还是生产环境，Ollama 都能无缝部署。Docker 镜像已发布到 Docker Hub，支持一键容器化运行。

## 快速上手：三步开启本地 AI

**第一步：安装 Ollama**

```bash
# macOS / Linux
curl -fsSL https://ollama.com/install.sh | sh

# Windows
irm https://ollama.com/install.ps1 | iex
```

**第二步：运行模型**

```bash
ollama run gemma4
```

**第三步：调用 API**

```bash
curl http://localhost:11434/api/chat -d '{
  "model": "gemma4",
  "messages": [{"role": "user", "content": "Hello"}]
}'
```

就是这么简单。**从安装到运行，全程不超过 5 分钟**，而云端 API 的配置和鉴权流程通常需要更长时间。

## 技术亮点分析：Ollama 的架构优势

**1. 基于 llama.cpp 的高效推理**

llama.cpp 是开源社区最成熟的本地推理引擎，支持量化模型和 GPU 加速。Ollama 在此基础上封装了更易用的接口，开发者无需关心底层细节。

**2. GGUF 格式标准化**

GGUF（GPT-Generated Unified Format）是 llama.cpp 提出的模型格式标准，支持多种量化级别（FP16、Q4_K_M、Q8_0 等）。Ollama 原生支持 GGUF，意味着你可以灵活选择模型精度与性能的平衡点。

**3. Modelfile 自定义配置**

通过 Modelfile，你可以自定义模型参数：

```
FROM gemma4
PARAMETER temperature 0.7
PARAMETER num_ctx 4096
SYSTEM "你是一个专业的编程助手"
```

这种灵活性让 Ollama 不仅是一个运行工具，更是一个**模型配置平台**。

**4. 多模型并发管理**

Ollama 支持同时运行多个模型实例，每个模型独立管理资源。这对于需要多模型协作的场景（如 RAG 系统、Agent 框架）非常友好。
