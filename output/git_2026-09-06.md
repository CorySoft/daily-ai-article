# Codenotch：一个屏幕边缘的 AI 用量管家

当开发者同时使用 Claude Code、Cursor、Codex 等多款 AI 编程工具时，用量焦虑无处不在——每个工具都有独立的配额窗口，切换间容易忘记剩余量，超额停机往往猝不及防。Codenotch 以优雅方式解决这一痛点：一个黑曜石般的屏边圆环，静默地告诉你"还剩多少、是否在工作、何时重置"。

## 四边皆屏，一隅藏环

Codenotch 是一个 macOS 应用，它在屏幕边缘固定一个小型黑色圆环，实时显示各编程助手的用量消耗情况。最精妙的设计在于：**它从不额外登录**，而是直接借用你 Mac 上已存在的凭证——安装好任意一个 AI 工具，对应的用量环便会自动出现。

![配图描述：深邃的黑色天鹅绒背景上，四边悬浮着四个半透明的玻璃圆环，每个圆环内嵌着不同色调的光晕，从边缘向中心渐暗，仿佛夜空中的星环静静悬浮]

> 四个 AI 用量，一个屏边环，一目了然。

其支持的 Provider 列表颇为完整：Claude Code、Cursor、Codex、Antigravity、GLM，每个都通过官方接口读取数据。Claude Code 的用量环与它自身 `/usage` 命令显示的数据完全一致，从不产生分歧。

更贴心的是多账号支持。通过 `CLAUDE_CONFIG_DIR=~/.claude-work claude` 隔离的工作账号，会生成一个独立的 **Claude (work)** 环，与个人账户环并排显示，各自拥有独立的限额、会话和设置行。

## 不止于用量，更回答"是否在工作"

多数同类工具只展示"剩多少"，而 Codenotch 进一步回答 **"它是否还在工作？"** —— 当会话活跃时，圆环内有一道细弧旋转；当会话阻塞、等待你的输入时，圆环变为琥珀色脉冲。

![配图描述：深空背景下，一枚圆环悬浮于边缘，环内有一道细弧光晕缓缓旋转，环的外沿泛着微弱的琥珀色脉动，如同呼吸般明暗交替]

悬停圆环可查看当前所有活跃会话的名称、运行位置和等待内容。这让开发者无需切换窗口，就能判断哪个 AI 工具在"思考"，哪个在"等你"。

Settings 区域以一枚" orb "形式呈现于圆环下方——静止时是一段弧线，点击后展开完整设置面板。所有数据在关闭工具后仍可追溯，但不会保留敏感凭证。

## 快速上手，三步即达

```bash
brew install xcodegen && make run
```

或使用演示模式预览效果：

```bash
CODENOTCH_DEMO=1 make run
```

安装 Claude Code、Cursor 等工具并登录后，Codenotch 即可自动识别。设置界面简洁直观，可切换各 Provider 开关、调整圆环位置（上/下/左/右四边自适应）。

## 技术亮点：接口抽象与隐私优先

从工程视角看，Codenotch 的设计值得称道。

**统一抽象层**：Swift 实现的 `UsageProvider` 接口统一了各来源的数据读取方式，Claude Code 走 OAuth token，Cursor 读本地 SQLite，Codex 调 API 并 fallback 到 rollout log，GLM 借用已有工具的 settings.json——每种协议都被封装在统一的契约下。

**零侵入隐私**：项目明确声明"从不单独登录任何服务"。在 Settings 中关闭某 Provider 后，不仅停止读取，还会清除已获取的用量数据，且不影响原工具的登录状态。

**安全更新**：采用 Sparkle 框架实现自动更新，所有更新包通过 EdDSA 签名保障完整性，避免中间人篡改风险。

![配图描述：一座透明的水晶金字塔，每一层代表不同的数据来源，底层是 SQLite 文件、中间层是 OAuth token、顶层是 API 响应，所有数据流向上汇聚成一枚发光的圆环]

**屏幕边缘自适应**：圆环可贴附于四边任意一侧，右侧和左侧保持垂直列布局，顶部和底部改为横向排列。在带有硬件 Notch 的 Mac 上，顶部放置会完美贴合硬件凹槽，两者融为一体而非并排。

## 适用场景与未来展望

Codenotch 最适合两类人群：

- **多工具并行开发者**：同时使用 Claude Code、Cursor、Codex 等，需要全局监控用量上限，避免意外超额导致工作中断
- **配额敏感用户**：对月度/周度用量窗口有清晰认知需求，希望一眼掌握"何时重置、还剩多少"

当前版本支持五大 Provider，覆盖了主流 AI 编程助手。随着 Anthropic、OpenAI、Google 等持续推出新的用量策略，Codenotch 的 `UsageProvider` 扩展架构使其能轻松接入新服务。

> 用量管理不应成为开发者的额外负担。好的工具应当如空气般存在——不打扰，但不可或缺。

Codenotch 正朝这个方向演进：一个静默的屏边管家，让用量焦虑消散于无形。
